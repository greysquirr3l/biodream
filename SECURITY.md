# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.2.x   | ✅        |
| 0.1.x   | ❌        |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Use [GitHub Private Vulnerability Reporting](https://github.com/greysquirr3l/biodream/security/advisories/new)
to disclose the issue privately.

Include:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a minimal proof-of-concept
- Any suggested mitigations (if known)

We aim to acknowledge reports within **48 hours** and provide a fix or
mitigation plan within **7 days** of confirmation.
